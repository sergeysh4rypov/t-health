# 🧬 T-Health AI Pro

![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)

**T-Health AI** — это интеллектуальная система предиктивной аналитики здоровья. Приложение использует классическое машинное обучение для оценки биологического возраста и генеративный ИИ для персональной интерпретации биомаркеров.

[🔗 Открыть приложение](https://t-health.streamlit.app/)

## 🚀 Основные возможности
* **Predictive ML:** Модель `RandomForestRegressor`, обученная на синтетических данных, рассчитывает био-возраст на основе 6 ключевых параметров.
* **AI Expert Insight:** Интеграция с **Google Gemini 3 Flash** для глубокого анализа показателей и выдачи рекомендаций.
* **Glassmorphism UI:** Современный адаптивный интерфейс с использованием кастомного CSS.
* **Instant Analysis:** Моментальная визуализация разрыва между паспортным и биологическим возрастом.

## 🛠 Технологический стек
* **Core:** Python 3.10+
* **ML:** Scikit-learn (Random Forest)
* **LLM:** Google Gemini API
* **Frontend:** Streamlit (Custom CSS/Glassmorphism)
* **DevOps:** GitHub, Streamlit Cloud
